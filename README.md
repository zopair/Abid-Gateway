# عابِد | Abid Gateway

واجهة تصورية عربية متجاوبة لعرض فكرة حساب العمل الحر الدولي بالدولار، مع إمكانية محاكاة احتساب الرصيد بالجنيه المصري.

## المعاينة

https://zopair.github.io/Abid-Gateway/

## محتويات المشروع

- `index.html` — الصفحة المستقلة الوحيدة المسؤولة عن عرض الواجهة.
- `.github/workflows/pages.yml` — ينشر الصفحة الرئيسية مباشرة على GitHub Pages.

لا تحتاج الواجهة إلى تثبيت حزم أو تشغيل خادم بناء؛ تعتمد على HTML وCSS وJavaScript، مع تحميل Cairo وTailwind CSS عبر CDN.

## ملاحظات النموذج

هذا نموذج تصوري للعرض فقط. الأرصدة وأرقام الحسابات وسعر الصرف والمعاملات افتراضية، وزر التحويل يعرض محاكاة حسابية ولا ينفذ تحويلًا أو إيداعًا حقيقيًا. الواجهة مستقلة ولا تمثل تطبيق InstaPay الرسمي أو شراكة مع بنك أو جهة.
